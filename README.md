# expense-tracker

Консольный трекер расходов (Expense Tracker CLI)

Приложение на Python для учета личных финансов. Позволяет записывать траты, отслеживать статистику и управлять историей расходов. Данные сохраняются локально в базу данных SQLite, поэтому не теряются после закрытия программы.

Стек:
Язык: Python 3
База данных: SQLite (встроенная библиотека sqlite3)
Работа с датами: библиотека datetime
Архитектура: разделение логики базы данных (database.py) и пользовательского интерфейса (main.py)

Основной функционал
1. Управление тратами (CRUD)
Добавление: запись новой траты с указанием категории, суммы и даты (по умолчанию ставится сегодняшняя).
Просмотр: вывод всех трат с уникальным id, сортировка по дате (от старых к новым).
Удаление: удаление конкретной записи по её id.

2. Аналитика и статистика
Вывод общей суммы всех трат
Поиск категории с максимальной суммой трат (через GROUP BY и SUM).
Поиск дня с максимальной суммой трат.
Расчет среднего расхода в день за выбранный период (считает только уникальные дни, когда были траты).

3. Управление базой данных
Полная очистка базы (с подтверждением действия).
Очистка трат за выбранный период дат (с подтверждением).
Валидация и защита от ошибок
Проверка ввода: программа не упадет, если ввести буквы вместо цифр.
Защита от пустого ввода.
Строгая валидация дат: проверка не только формата YYYY-MM-DD, но и того, что такой день физически существует (через datetime.strptime).
Запрет на добавление отрицательных сумм или нуля.
Использование параметризованных SQL-запросов (защита от SQL-инъекций).

Как запустить:
1. Клонируйте репозиторий.
2. Убедитесь, что у вас установлен Python 3.
3. Запустите программу командой:  python main.py
